Apple-1 WOZ Monitor (WOZMON) — Soft provenance
==============================================

Soft≠Physical. This tree hosts a Soft reconstruction of the classic ~256-byte
Apple-1 Hex Monitor at $FF00 for the mos6502-logos cycle twin. No Digilent
flash. No silicon claim. No real PIA timing / NTSC / physical Apple-1.

Memory map (Soft Apple-1-ish)
-----------------------------
  $0000–$0FFF / $0000–$1FFF  Soft RAM (4K/8K)
  $0200–$027F                Wozmon input buffer (IN)
  $D010 KBD                  Soft PIA.A keyboard data (bit7 set on char)
  $D011 KBDCR                Soft PIA.A keyboard control (bit7 = key ready)
  $D012 DSP                  Soft PIA.B display (bit7 = busy; Soft always ready)
  $D013 DSPCR                Soft PIA.B control (accepted, not timed)
  $FF00–$FFFF                WOZMON ROM image

Reset vector in image: $FFFC/$FFFD → $FF00
